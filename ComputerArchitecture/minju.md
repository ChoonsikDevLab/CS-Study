# 2. 컴퓨터 구조
컴퓨터의 하드웨어 구성 요소와 동작 원리를 이해하기 위한 핵심 개념

## 1) CPU

### 레지스터의 종류
- **프로그램 카운터**(PC): 다음에 실행할 명령어의 주소를 저장
- **명령어 레지스터**(IR): 현재 해석할 명령어를 저장
- **범용 레지스터**: 데이터, 주소 등 다용도로 사용
- **플래그 레지스터**: 연산 결과나 CPU 상태에 대한 부가 정보 저장
- **스택 포인터**: 메모리의 스택 영역 최상단을 가리킴

### 인터럽트
CPU의 정상적인 작업을 방해하는 신호

#### 인터럽트 종류
- **동기 인터럽트**(예외): CPU 내부에서 발생 (예: 프로그래밍 오류)
- **비동기 인터럽트**(하드웨어 인터럽트): 외부 요인에 의해 발생

#### 인터럽트 처리 과정
1. 입출력장치가 **인터럽트 요청 신호**를 보냄
2. CPU는 **인터럽트 플래그**를 확인하여 수용 여부 결정
3. 현재 작업을 백업
4. **인터럽트 벡터**를 참조하여 **인터럽트 서비스 루틴**(ISR) 실행
5. ISR 실행 후 백업된 작업을 복구하여 재개

### CPU 성능 향상 기법

#### 클럭 속도
- CPU가 동작하는 시간 단위
- 빠를수록 성능이 좋지만 발열 문제 발생

#### 멀티코어
- 하나의 CPU 안에 여러 개의 코어를 포함하는 기술

#### 멀티스레드
- **하드웨어 스레드**: 하나의 코어가 동시에 처리하는 명령어 단위
- **소프트웨어 스레드**: 하나의 프로그램에서 독립적으로 실행되는 단위

#### 동시성 vs 병렬성
- **병렬성**: 여러 작업을 물리적으로 동시에 처리 (멀티코어)
- **동시성**: 여러 작업을 번갈아 가며 빠르게 처리하여 동시 처리처럼 보이게 함

#### 명령어 파이프라이닝
- 명령어 처리 과정을 여러 단계로 나누어 각 단계를 동시에 실행
- **파이프라인 위험**: 데이터, 제어, 구조적 위험으로 인한 성능 저하 가능

#### CISC vs RISC
- **CISC**: 복잡하고 다양한 기능의 명령어 집합 (가변 길이)
- **RISC**: 단순하고 규격화된 명령어 집합 (파이프라이닝에 유리)

## 2) 메모리

### RAM(Random Access Memory)
실행 중인 프로그램을 저장하는 휘발성 저장장치

#### RAM의 종류
- **DRAM**(Dynamic RAM): 주기적 재활성화 필요, 저렴, 메인 메모리용
- **SRAM**(Static RAM): 전원 공급 시 데이터 유지, 빠르고 비쌈, 캐시 메모리용
- **SDRAM**(Synchronous DRAM): 클럭 신호에 동기화되어 작동
- **DDR SDRAM**: 한 클럭에 두 번 데이터 전송 (DDR, DDR2, DDR3, DDR4 등)

### 엔디안(Endianness)
여러 바이트로 구성된 데이터를 메모리에 저장하는 순서

- **빅 엔디안**: 상위 바이트부터 낮은 주소에 저장 (사람이 읽는 순서와 동일)
- **리틀 엔디안**: 하위 바이트부터 낮은 주소에 저장 (수치 계산에 유리)

### 캐시 메모리
CPU와 메모리 사이의 속도 차이를 줄이기 위한 고속 저장장치

#### 캐시 계층
- **L1 캐시**: 가장 빠르고 용량이 작음, CPU 코어에 가장 가까움
- **L2 캐시**: 중간 속도와 용량
- **L3 캐시**: 가장 느리지만 용량이 큼

#### 캐시 동작
- **캐시 히트**(Cache Hit): CPU가 찾는 데이터가 캐시에 있는 경우
- **캐시 미스**(Cache Miss): CPU가 찾는 데이터가 캐시에 없는 경우

#### 참조 지역성의 원리
- **시간 지역성**: 최근 접근한 데이터에 다시 접근할 가능성이 높음
- **공간 지역성**: 접근한 데이터 주변에 접근할 가능성이 높음

#### 캐시 쓰기 정책
- **즉시 쓰기**(Write-through): 캐시와 메모리에 동시에 씀 (일관성 유지, 속도 저하)
- **지연 쓰기**(Write-back): 캐시에만 쓰고 나중에 메모리에 반영 (속도 빠름, 일관성 문제 가능)


## 3) 보조기억장치와 입출력장치

### RAID(Redundant Array of Independent Disks)
여러 개의 보조기억장치를 하나처럼 사용하여 데이터 안전성이나 성능을 높이는 기술

- **RAID 0**(스트라이핑): 데이터를 분산 저장하여 속도 향상, 안정성 낮음
- **RAID 1**(미러링): 데이터를 복제 저장하여 안정성 향상, 용량 효율 낮음
- **RAID 4, 5, 6**: 패리티 정보를 사용하여 데이터 오류 검출 및 복구

### 입출력 기법

#### 입출력 구성 요소
- **장치 컨트롤러**: CPU와 입출력장치 사이의 통신을 중개하는 하드웨어
- **장치 드라이버**: 장치 컨트롤러를 작동시키는 소프트웨어

#### 입출력 방식
- **프로그램 입출력**(PIO): CPU가 입출력 명령어를 직접 실행
- **인터럽트 기반 입출력**: 입출력장치가 작업 완료 시 CPU에 인터럽트 전송
- **DMA**(Direct Memory Access): DMA 컨트롤러가 CPU 대신 데이터 전송 담당

### GPU(Graphic Processing Unit)
수많은 코어를 활용하여 대량의 그래픽 연산이나 병렬 처리에 특화된 장치

- 단순 연산을 병렬적으로 빠르게 처리
- 머신러닝, 암호화폐 마이닝 등에도 활용

<summary><b>CPU와 GPU의 차이점에 대해 설명해주세요.</b></summary>
<br>
CPU는 복잡한 계산이나 순차적인 작업 처리에 최적화된 범용 프로세서입니다. 소수의 강력한 코어를 가지고 있으며, 다양한 종류의 명령어를 처리하는 데 특화되어 있습니다.<br><br>
GPU는 수많은 코어를 활용하여 단순 연산을 병렬적으로 동시에 처리하는 데 특화된 장치입니다. 원래는 그래픽 처리를 위해 개발되었지만, 현재는 대규모 병렬 연산이 필요한 머신러닝이나 데이터 분석 등에도 널리 사용됩니다.
</details>

<details>
<summary><b>캐시 미스(Cache Miss)가 발생하면 어떤 일이 일어나며, 왜 성능에 좋지 않은가요?</b></summary>
<br>
캐시 미스는 CPU가 필요한 데이터를 매우 빠른 캐시 메모리에서 찾지 못한 경우를 말합니다.<br><br>
CPU는 속도가 느린 주 기억장치(RAM)에 직접 접근하여 데이터를 가져와야 합니다. CPU와 RAM 사이에 속도 차이가 있기 때문에 이 과정에서 CPU는 데이터가 도착할 때까지 기다려야 하는 지연 시간(Latency)이 발생합니다.
</details>

<details>
<summary><b>RAM과 하드 디스크의 차이점에 대해 설명해주세요.</b></summary>
<br>
가장 큰 차이점은 휘발성과 용도입니다.<br><br>
RAM은 전원이 꺼지면 데이터가 사라지는 휘발성 저장장치로 속도가 매우 빠릅니다. 그래서 현재 실행 중인 프로그램과 데이터를 임시로 저장하는 주기억장치로 사용됩니다.<br><br>
하드 디스크는 전원이 꺼져도 데이터가 유지되는 비휘발성 저장장치로, 속도는 RAM보다 훨씬 느립니다. 그래서 프로그램이나 파일을 영구적으로 보관하는 용도의 보조기억장치로 사용됩니다.
</details>

<details>
<summary><b>병렬성(Parallelism)과 동시성(Concurrency)의 차이점에 대해 설명해주세요.</b></summary>
<br>
병렬성은 멀티 코어 환경에서 여러 작업이 물리적으로 정말 동시에 처리되는 것을 의미합니다.<br><br>
동시성은 하나의 코어가 여러 작업을 아주 짧은 시간 간격으로 번갈아 가며 처리하여 마치 논리적으로 동시에 처리되는 것처럼 보이게 하는 것입니다.
</details>
